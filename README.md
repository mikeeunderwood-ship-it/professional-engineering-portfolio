This site showcases my engineering identity, project work, writing, and professional background in a clean, fast, and highly maintainable architecture.

The portfolio is intentionally minimal, focusing on clarity, performance, and developer experience.  
It also serves as a foundation for future demo projects that highlight distributed systems, API engineering, and hands-on technical depth.

## 🚀 Deployment (Netlify)

This portfolio is deployed using **Netlify**, providing fast global CDN delivery, automatic builds, and seamless integration with GitHub.

### **Automatic Deploys from GitHub**
Netlify is configured to automatically rebuild and redeploy the site whenever changes are pushed to the `main` branch.

### **Build Settings**
These are the exact settings used by Netlify:

- **Build Command:** `npm run build`
- **Publish Directory:** `dist`
- **Node Version:** 18.x (via Netlify defaults or `.nvmrc`)
- **Framework Preset:** None (Vite handles the build)

### **Environment**
No environment variables are required for this project.

### **Manual Deployment**
You can trigger a manual deploy at any time from the Netlify dashboard:

**Netlify Dashboard → Deploys → Trigger Deploy**

### **Production URL**
https://mikeeunderwood.dev

Netlify handles HTTPS, caching, and asset optimization automatically.
